# Data Science & Analytics  Internship Tasks Repository

## Overview

This repository contains five machine learning tasks completed as part of my internship program. Each task focuses on different aspects of data analysis, visualization, and predictive modeling using real-world datasets. The work demonstrates practical skills in data preprocessing, exploratory data analysis, machine learning model development, and performance evaluation.

The repository is organized into separate folders for each task, ensuring clarity, maintainability, and professional project structure.

The main objectives of this repository are:

## Tasks Included

### Task 1: Exploring and Visualizing a Simple Dataset

This task focuses on understanding the dataset through exploratory data analysis (EDA) and creating visualizations to identify patterns and trends.

### Task 2: Credit Risk Prediction

This task involves building a classification model to predict whether a customer is likely to default on credit based on financial and demographic data.

### Task 3: Customer Churn Prediction (Bank Customers)

This task aims to predict whether a bank customer will leave the bank using machine learning techniques and customer behavior data.

### Task 4: Predicting Insurance Claim Amounts

This task uses regression techniques to estimate the amount of insurance claims based on customer and policy information.

### Task 5: Personal Loan Acceptance Prediction

This task focuses on predicting whether a customer will accept a personal loan offer using classification algorithms.
